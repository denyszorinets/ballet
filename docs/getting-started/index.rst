Getting started
===============

Ballet runs AI coding agents on your projects' tickets: you plan the
work with a planner agent, approve the plan, and agents implement,
review, verify and merge it — asking you only when they must.

.. toctree::
   :maxdepth: 1

   quickstart
   real-project

Start with the :doc:`quickstart`: Ballet on your machine with a fake
model, a demo repository and a first ticket done by agents, in about ten
minutes, without an API key. Then :doc:`real-project` connects a real
model and a GitHub repository. The :doc:`/user-guide/index` covers
everyday use.
